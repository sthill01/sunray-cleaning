# Analytics, KPIs, and Monitoring Standards

## Objective

Measure whether SRAAP is improving authority, technical health, visibility, and revenue potential.

## KPI Categories

### AI Visibility

- Number of target prompts where Sun Ray appears.
- Position or prominence in AI answers.
- Citation page used by AI systems when available.
- Competitor mentions.
- Missing entity signals.

### Technical Health

- Build success.
- Broken internal links.
- Missing metadata.
- Missing schema.
- Missing alt text.
- Route coverage.
- Sitemap coverage.
- Performance issues.

### Content Health

- Pages by service and location.
- Thin content candidates.
- Orphan pages.
- Stale pages.
- Internal-link opportunities.
- Image coverage.

### Business Outcomes

- Quote form starts.
- Quote submissions.
- Call clicks.
- SMS clicks.
- Lead source attribution.
- Service-area lead distribution.

## Monitoring Rules

Monitoring should create actionable findings, not vanity metrics.

Every recurring report should answer:

- What changed?
- Why does it matter?
- What should Codex do next?
- Is user action required?
