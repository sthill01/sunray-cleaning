# Content and Editorial Standards

## Purpose

Content should make Sun Ray more useful, trustworthy, and citeable.

## Voice

Sun Ray content should be:

- Clear.
- Practical.
- Local.
- Warm.
- Professional.
- Specific.

Avoid:

- Generic filler.
- Unsupported superlatives.
- Keyword stuffing.
- Fake urgency.
- Invented proof.

## Page Quality Checklist

Before creating or publishing content, check:

- Does this match a real customer or AI search intent?
- Does it add value beyond an existing page?
- Does it link to relevant services?
- Does it link to relevant locations?
- Does it include quote guidance?
- Does it support schema?
- Does it avoid unsupported claims?

## Human Review

Codex should request human review when content:

- Makes sensitive business claims.
- Mentions pricing beyond documented guidance.
- Uses customer stories not present in source material.
- Announces services, areas, or policies not already documented.
- Could affect legal, insurance, or customer expectation risk.

## Content Types

Priority types:

- Service pages.
- Location pages.
- Neighborhood pages.
- AI authority pages.
- Blog guides.
- FAQ resources.
- Checklists.
- Comparison pages.
- Seasonal guides.
