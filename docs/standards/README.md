# Standards

This folder defines how Codex should engineer, optimize, write, measure, and validate SRAAP.

## Standards Index

- `engineering.md`: code, build, Git, validation, and repository rules.
- `ai-optimization.md`: ChatGPT, Claude, Gemini, Grok, Perplexity, and Google AI Overviews rules.
- `local-seo-entity-authority.md`: local SEO, entity, service, and location authority rules.
- `content-editorial.md`: content generation and editorial quality rules.
- `analytics-kpis.md`: measurement, dashboards, KPIs, and monitoring rules.

## Standard Hierarchy

When standards conflict:

1. Constitution.
2. Business truth and legal/factual safety.
3. Architecture.
4. Engineering standards.
5. AI and SEO standards.
6. Content standards.
7. Automation convenience.
