# Decisions

This folder stores durable decisions for SRAAP.

Use an ADR when changing:

- Build architecture.
- Route architecture.
- Content model.
- Schema strategy.
- Automation behavior.
- Deployment strategy.
- Data or monitoring strategy.
- Governance model.

## ADR Format

Each ADR should include:

- Title.
- Date.
- Status.
- Context.
- Decision.
- Alternatives considered.
- Consequences.
- Follow-up tasks.
