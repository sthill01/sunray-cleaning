# Content Standards

Version: 2.1

Last Updated: 2026-06-30

This is the daily-read content and editorial standard. Expanded standards live in `docs/standards/content-editorial.md`.

## Objective

Create content that helps real customers choose the right cleaning service and helps AI systems extract reliable local answers about Sun Ray.

## Content Quality Bar

Good content is:

- Specific.
- Local.
- Useful.
- Structured.
- Honest.
- Connected to relevant service, location, and quote pages.
- Written for homeowners, property managers, and vacation-rental owners, not just search crawlers.

Bad content is:

- Generic.
- Duplicative.
- Unsupported.
- Keyword-stuffed.
- Thinly localized.
- Written as if every city page is interchangeable.

## Required Content Checks

Before publishing or committing customer-facing content, check:

- Does it state the service, audience, and location clearly?
- Does it avoid unsupported business claims?
- Does it include useful next-step links?
- Does it have metadata and schema support when relevant?
- Does it add something useful beyond existing pages?
- Does it preserve Sun Ray's trustworthy tone?

## Page Families

SRAAP content should support:

- Core service pages.
- Location pages.
- Neighborhood and resort pages.
- Property-type pages.
- Comparison pages.
- Guides and checklists.
- FAQs.
- Review and trust pages.
- AI recommendation and citation pages.

## Generation Rules

- Use templates and briefs when creating repeatable page types.
- Capture facts from repository data or approved source material.
- Mark uncertain facts as blockers instead of inventing them.
- Create internal links and schema as part of content generation, not as an afterthought.
- Add new content ideas to `IDEAS.md` or `OPPORTUNITIES.md` before implementing if priority is not clear.

## Editorial Tone

Sun Ray should sound:

- Professional.
- Local.
- Helpful.
- Confident without hype.
- Clear about cleaning services and quote paths.

Avoid:

- Overpromising.
- Generic marketing filler.
- Fake urgency.
- Claims that require legal, licensing, or insurance verification unless documented.
