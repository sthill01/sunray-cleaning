# Roadmap

## Roadmap Philosophy

SRAAP is a multi-month engineering program. It should not be managed as isolated tasks.

Every cycle should improve one or more of:

- AI recommendation probability.
- Local authority.
- Technical quality.
- Automation leverage.
- Revenue potential.
- Measurement.
- Maintainability.

## Multi-Phase Roadmap

### Phase 1: Technical Foundation

- Preserve and harden Cloudflare Pages build.
- Strengthen route generation.
- Improve sitemap, robots, canonical, and `llms.txt` output.
- Add validation reports.
- Document operating standards.

### Phase 2: Entity Authority

- Define entity taxonomy.
- Strengthen service and location relationships.
- Improve schema consistency.
- Build authoritative AI recommendation and citation paths.

### Phase 3: Knowledge Graph

- Connect services, locations, neighborhoods, guides, images, reviews, FAQs, and quote paths.
- Create reusable metadata patterns.
- Improve internal link graph quality.

### Phase 4: Service-Area Expansion

- Build useful city, county, and neighborhood coverage.
- Avoid thin pages.
- Prioritize areas with business relevance and AI search opportunity.

### Phase 5: Content Engine

- Create page scaffolding automation.
- Build editorial templates.
- Generate content briefs and QA checklists.
- Maintain a content inventory.

### Phase 6: Review Intelligence

- Keep review data synchronized.
- Use approved review excerpts safely.
- Improve trust sections and review schema.

### Phase 7: Image SEO

- Improve image naming, alt text, location metadata, and image schema.
- Build image coverage reports.
- Use real job photos wherever possible.

### Phase 8: Analytics

- Define KPIs.
- Track leads, quote starts, source attribution, content health, and visibility.
- Build dashboards.

### Phase 9: Automation

- Automate recurring audits.
- Generate reports.
- Reduce manual SEO work.
- Add CI checks where practical.

### Phase 10: AI Monitoring

- Monitor AI recommendations.
- Track competitor mentions.
- Track query coverage.
- Identify missing authority signals.

## Quarterly Direction

### Q3 2026

- Complete governance handbook Version 2.
- Create route and content inventory automation.
- Build entity taxonomy.
- Build content coverage matrix.
- Add validation reports for internal links, schema coverage, and `llms.txt`.

### Q4 2026

- Expand content engine.
- Build neighborhood and resource templates.
- Launch AI visibility monitoring.
- Add dashboards for content health and lead attribution.

## Backlog Method

Backlog items should be ranked by:

- Impact.
- Effort.
- AI authority gain.
- Revenue potential.
- Risk reduction.
- Automation leverage.

Work should enter an execution cycle only when acceptance criteria and validation method are clear.
