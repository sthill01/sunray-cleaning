# 12 Decisions

## Purpose

This folder records durable decisions for Program Alpha.

Use decision records when changing:

- Architecture.
- Build pipeline.
- Routing model.
- Content model.
- Schema strategy.
- Automation behavior.
- Deployment strategy.
- Data or monitoring strategy.

## Decision Record Format

Each decision should include:

- Title.
- Date.
- Status.
- Context.
- Decision.
- Alternatives considered.
- Consequences.
- Follow-up tasks.
