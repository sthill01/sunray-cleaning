# Sun Ray AI Authority Platform

Version 1, 2026

This folder is the operating handbook for Program Alpha. It defines how Steve and Codex run Sun Ray Cleaning as a long-term AI authority, technical SEO, content, automation, and analytics platform.

## Operating Roles

Steve is the Chief Product Architect.

Steve owns the vision, business strategy, market positioning, AI authority goals, entity development, content architecture, information architecture, automation philosophy, analytics direction, and final business judgment.

Codex is the Lead Software Engineer.

Codex owns implementation, repository architecture, file structure, refactoring, build optimization, test strategy, validation, commits, pull requests, documentation hygiene, and technical quality.

## Definition of Done

Program Alpha work is not done until:

- The implementation matches the Constitution and relevant standards.
- The existing Cloudflare Pages pipeline still works.
- Build and validation commands have been run or an explicit blocker is documented.
- Internal links, route shape, sitemap output, and `llms.txt` behavior are checked when affected.
- Schema output is checked when affected.
- Documentation is updated when the work changes policy, architecture, or future workflow.
- The final report names exact paths changed, validations run, and any remaining risk.

## Non-Goals

Program Alpha does not mean rewriting the whole site for its own sake. It means compounding authority through disciplined architecture, automated production, high-quality content, strong local entity signals, and continuous validation.
