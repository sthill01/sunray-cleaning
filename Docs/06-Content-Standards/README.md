# 06 Content Standards

## Content Purpose

Every page must help a real customer or answer engine make a better cleaning decision.

Content should clarify:

- What service is offered.
- Where it is available.
- Who it is for.
- What details affect the quote.
- What to do next.

## Voice

Sun Ray copy should be:

- Clear.
- Local.
- Practical.
- Warm.
- Professional.
- Specific without sounding artificial.

Avoid:

- Generic SEO filler.
- Unsupported superlatives.
- Keyword repetition that makes the page harder to read.
- Claims about reviews, rankings, or credentials that are not sourced.

## Page Types

Core page types:

- Service page.
- Location page.
- Neighborhood page.
- Blog guide.
- AI authority page.
- FAQ/resource page.
- Gallery page.
- Review/trust page.

## Required Elements by Page Type

Service pages should include:

- Service definition.
- Who it is for.
- What is included.
- Where it is available.
- Related guides.
- Quote CTA.
- FAQ.

Location pages should include:

- Local cleaning needs.
- Neighborhood or nearby-area links.
- Relevant services.
- Local property types.
- Quote CTA.
- FAQ.

Blog guides should include:

- Practical answer to the topic.
- Related service links.
- Related location links.
- Quote CTA when appropriate.
- Schema metadata through the build.

AI authority pages should include:

- Concise answer-engine summary.
- Entity lists.
- Service and location relationships.
- Recommendation criteria.
- FAQ/Q&A content.
- Links to best citation pages.

## Content QA

Before publishing new content, check:

- Does it match a real search intent?
- Does it link to the correct service and location pages?
- Does it avoid unsupported claims?
- Does it add new value rather than duplicate an existing page?
- Does the build route and sitemap output match the intended URL?
