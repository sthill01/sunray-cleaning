# 11 Backlog

## Prioritization Framework

Prioritize work that improves:

1. AI recommendation probability.
2. Local service/location authority.
3. Build and validation reliability.
4. Automation leverage.
5. Content production quality.
6. Measurement and monitoring.

## Near-Term Backlog

### P0

- Establish Program Alpha handbook.
- Add decision log process.
- Create entity taxonomy source of truth.
- Audit generated `llms.txt` coverage.
- Audit route inventory and sitemap coverage.

### P1

- Build content inventory report.
- Build service/location coverage matrix.
- Add schema spot-check automation.
- Add AI authority internal-link report.
- Create page template standards for neighborhoods and resources.
- Create image alt text and image schema coverage report.

### P2

- Build AI visibility monitor.
- Build competitor content monitor.
- Create content health dashboard.
- Create quote/lead attribution dashboard.
- Add CI checks for build and internal links.

### P3

- Neighborhood page factory.
- FAQ/resource page factory.
- Automated content refresh recommendations.
- Local proof asset library.
- Review and gallery import QA dashboard.

## Backlog Rules

- Backlog items should become sprint work only after acceptance criteria are clear.
- Automation items need dry-run and validation behavior.
- Content expansion items need taxonomy alignment before page creation.
