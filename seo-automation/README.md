# Sun Ray Webflow SEO Automation System

This is the working operating system for keeping Sun Ray Cleaning on Webflow while using AI-assisted page creation, SEO maintenance, and local/LLM search monitoring.

## Current Strategy

Webflow is the publishing layer. This repo is the staging, drafting, audit, and source-control layer.

Use the repo for:

- Page prototypes and Webflow import kits
- Blog/page drafts before they go into Webflow CMS
- SEO metadata, schema, FAQ, and internal-link planning
- Recurring local/LLM search monitoring outputs
- Competitor comparisons and keyword opportunity notes

Use Webflow for:

- Final visual editing
- CMS drafts and publishing
- Page settings, canonical URLs, redirects, and production publishing
- Client-friendly edits after content is staged

## Primary Goals

1. Win local search for Park City, Heber City, Midway, Summit County, and Wasatch County cleaning intent.
2. Win LLM/search-answer visibility for pricing, checklists, best-cleaner, and service-comparison queries.
3. Build a repeatable Webflow publishing cadence.
4. Keep Sun Ray Cleaning's entity information consistent across website, directories, reviews, and AI-cited sources.

## Weekly Cadence

Monday:

- Review competitor/local/LLM search snapshot.
- Pick one low-hanging keyword and one high-conversion keyword.
- Create or update a Webflow CMS draft.

Wednesday:

- Review and stage content in Webflow.
- Add internal links from related prior posts/pages.
- Add FAQ schema and page metadata.

Friday:

- Publish or schedule in Webflow.
- Record published URL.
- Add follow-up tasks for backlink, GBP post, and internal-link updates.

## Quality Bar For Every Page

- Local entity definition in first 100 words.
- Primary city/service phrase in H1 or H2.
- Direct answer paragraphs under question-style headings.
- 5-8 FAQs for AI search and long-tail snippets.
- FAQ, Service, LocalBusiness, or Article schema as appropriate.
- At least one service-page link and one location-page link.
- Clear CTA with `(801) 604-2189`.
- Specific local details: neighborhoods, landmarks, seasonal conditions, property types.
- Updated date and author/business credibility block.
